# API de Gestão Hospitalar - Node.js & Fastify

API desenvolvida por Lucas silva souza com foco em performance e arquitetura limpa para controle de fluxo de pacientes, leitos e especialidades em ambiente hospitalar. Projeto desenvolvido para portfólio e currículo em TI Hospitalar, Manmtendo algumas informações do paciente para consulta como KG, Altura e BPM, para melhor atendimento.!


# Tecnologias
- Node.js
- Fastify

# Como executar
1. Instale as dependências:
   npm install
   
2. Inicie o servidor:
   npm run dev
  

A API estará disponível em `http://localhost:3333`.
